Evaluation & Analysis

01

Evaluate a checkpoint

from map import eval

result = eval.run(
    paths,
    run_name="map-unprofiled-seed42",
    checkpoint=run.summary["checkpoint"],
    evaluation_name="map-unprofiled-final",
    seeds=(42,),
    set_size=24,
)
输出
batch unit  one cell line–drug pair
all doses   aggregated within that pair
no max_batches limit
splits//methods/map/runs//evaluations/map-unprofiled-final/{internal_test,external_test}/
evaluation.json · per_drug_metrics.csv · predictions_seed42.parquet
指标定义
指标方向口径
HVG Pearson Δ↑HVG 预测与真实扰动响应的 Pearson 相关。
HVG Direction Accuracy↑HVG 上调、下调或不变方向一致率。
HVG PDS↑原论文 Manhattan 距离的扰动识别分数。
Top-k DEG Pearson Δ↑同一 cell line–drug 的显著 DEG 中按真实效应量取前 k。
Top-k DEG Direction / Overlap↑Top-k DEG 方向一致率与集合重叠。
DEG AUROC / AUPRC↑预测效应量识别显著 DEG 的排序能力。
R² / PCC↑预测与真实表达的决定系数 / Pearson 相关。
MSE↓预测与真实表达均方误差。
Wasserstein / MMD / Sinkhorn↓预测与真实单细胞分布距离。
CSS↓协方差结构的归一化 Frobenius 差异。
Disentanglement / Biological↑因素分离程度与细胞群体响应综合分数。
Throughput / Peak GPU memory↑ / ↓每秒完成的 cell line–drug 条件与峰值显存。
