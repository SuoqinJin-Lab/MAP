指标定义
指标方向定义
HVG Pearson Δ越高越好预测与真实扰动响应差值在 HVG 上的 Pearson 相关。
HVG Direction Accuracy越高越好预测与真实响应方向（上调、下调或不变）一致的 HVG 比例。
HVG PDS越高越好扰动识别分数：真实配对相对其他配对的距离排名能力。
Top-k DEG Pearson Δ越高越好在显著 DEG 中按真实效应量选取前 k 个（示例为 50）后的 Δ Pearson 相关。
Top-k DEG Direction Accuracy越高越好Top-k DEG 的预测和真实响应方向一致率。
R² / PCC越高越好预测表达与真实表达的决定系数 / Pearson 相关。
MSE越低越好预测与真实表达值的均方误差。
Wasserstein Distance越低越好预测与真实表达分布之间的一维 Wasserstein 距离。
MMD越低越好基于 RBF 核的最大均值差异，衡量两组表达样本分布差异。
Sinkhorn Distance越低越好带熵正则的最优传输距离，用于比较预测和真实表达分布。
CSS越低越好预测与真实响应协方差矩阵的归一化 Frobenius 差异，描述 HVG 共表达/变异结构差异。
DEG AUROC / AUPRC越高越好用预测效应量区分显著 DEG 与非 DEG 的 ROC-AUC / PR-AUC。
Top-k DEG Overlap越高越好预测效应量排名前 k 与真实 Top-k DEG 的集合重叠比例。
Disentanglement Score越高越好预测响应中细胞群体和药物因素的可加分离程度。
Biological Score越高越好按细胞群体汇总的响应相关性、方向一致性和效应量相关性的综合分数。
Conditions per Second越高越好单位时间完成评估的 condition 数量。
Peak GPU Memory越低越好评估过程中观测到的 GPU 峰值显存占用。
